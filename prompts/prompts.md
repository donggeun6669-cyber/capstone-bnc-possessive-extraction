# 프롬프트 1–9

Codex(GPT-6.1 Sol High)에 넣은 프롬프트이다. 프롬프트 4–7은 첫 실행 뒤 같은 대화창에서 수정을 요청한 내용(값 표기)을 반영해 정리한 판이다.

## 프롬프트 1. 코퍼스 전처리 함수

```text
'bnc_tagged.txt' 파일을 읽고 처리한 후, 그 결과를 반환하는 파이썬 함수를 만들어줘.

입력 데이터 형식:
- 읽고 처리할 코퍼스는 의존구조 파싱(dependency parsing)이 된 파일
- 각 문장은 ‘<s id="숫자">’로 시작하고 ‘</s>’로 끝남.
- 단, 일부 문장은 ‘<s id=…>’ 줄 없이, 앞 문장의 ‘</s>’ 바로 다음 줄부터 시작함.
- 문장의 각 줄은 하나의 단어를 나타내며, 탭으로 구분된 7개의 정보를 포함함: 단어 형태, 품사(UPOS), 기본형(lemma), 단어 ID, 핵어 ID(head ID), 핵어(head word), 의존관계(deprel)

함수의 작동:
- 문장의 끝은 ‘</s>’ 줄로 판단한다. ‘</s>’가 나오면 그때까지 모은 단어 정보를 한 문장으로 저장하고, 다음 줄부터 새 문장을 시작한다. ‘<s id=…>’ 줄이 없어도 새 문장으로 처리하며, 앞 문장과 합치지 않는다.
- 각 문장에서 탭으로 구분된 7개의 값으로 이루어진 단어 정보들을 모아서 리스트로 만든다. 단어 정보가 7개의 값을 갖지 않으면 그 단어는 건너뛴다.
- 문장 ID는 ‘<s id="숫자">’ 줄에서 숫자만 뽑는다(따옴표와 기호 제외). ‘<s id=…>’ 줄이 없는 문장의 ID는 바로 앞에 ‘<s id=…>’ 줄이 있던 문장의 ID 뒤에 "-2", "-3"처럼 순번을 붙인 문자열로 한다.
- 문장 ID와 단어 정보 리스트를 튜플로 묶어서 결과 리스트에 추가한다.
- 함수 실행이 끝나면 전체 문장 수와 ‘<s id=…>’ 줄이 없던 문장 수를 출력한다.
- 함수의 매개변수에 다음을 포함한다: (filename="/content/bnc_tagged.txt")

반환 (출력 데이터): (문장 ID, 토큰 리스트) 형태의 튜플을 저장한 리스트
```

## 프롬프트 2. 명사 목록 전처리 함수

```text
'noun_list.txt' 파일을 읽고, noun_list라는 명사 딕셔너리를 생성해서 반환하는 파이썬 함수를 작성해 줘.

입력 데이터 형식:
- 파일의 각 줄에는 탭으로 구분된 3개의 값이 있음: 명사 기본형(lemma), 의미 부류, 출처
- 이 중 첫 번째 값(명사 기본형)만 사용한다.

함수의 작동:
- 파일의 각 줄에서 첫 번째 값(명사 기본형)을 소문자로 바꾼 문자열을 key로 하고, 빈 리스트 ‘[]’를 value로 해서 딕셔너리에 추가한다.
- 빈 줄은 건너뛴다.
- 함수 실행 결과는 출력하지 않고, 만들어진 딕셔너리를 반환한다.
- 함수의 매개변수에 다음을 포함한다: (filename="/content/noun_list.txt")

반환 (출력 데이터): 명사를 key로 하고 빈 리스트를 value로 하는 딕셔너리
```

## 프롬프트 3. 전체 용례 추출 함수

```text
다음 기능을 하는 데이터 추출 함수를 작성해 줘. 이 함수는 위 단계에서 생성된 두 결과를 입력 받아, 명사 목록에 있는 명사가 보통 명사로 쓰인 모든 용례를 수집하는 작업을 수행해야 해.

입력 데이터 형식:
- 코퍼스 데이터: (문장 ID, 토큰 리스트) 형태의 튜플을 담은 리스트
- 각 토큰 정보: [단어 형태, 품사, 기본형, 단어 ID, 핵어 ID, 핵어, 의존관계] (총 7개의 요소)
- 명사 딕셔너리: 명사를 key로 하고, 빈 리스트를 value로 갖는 defaultdict(list) 형태

함수의 작동:
1. 코퍼스 데이터 내의 각 문장에서 다음 조건을 모두 만족하는 토큰(목록 명사)을 찾는다.
   - 기본형(토큰 정보의 세 번째 요소)을 소문자로 바꾼 값이 명사 딕셔너리의 key에 포함됨.
   - 품사(토큰 정보의 두 번째 요소)가 "NOUN"임.
2. 조건을 만족하는 토큰을 찾을 때마다 다음 작업을 수행한다.
   - 해당 문장의 모든 단어를 공백으로 연결하여 문자열로 만들고,
   - 그 토큰의 기본형(소문자)을 key로 사용하여, (문장 ID, "-", 연결된 문장 문자열) 형태의 튜플을 명사 딕셔너리의 value 리스트에 추가한다.
3. 모든 문장 처리 후 수정된 명사 딕셔너리를 반환한다.

반환 (출력 데이터): 명사 용례 딕셔너리
```

## 프롬프트 4. ① 대명사 소유 용례 추출 함수

```text

입력 데이터 형식:
- 코퍼스 데이터: (문장 ID, 토큰 리스트) 형태의 튜플을 담은 리스트

- 명사 딕셔너리: 명사를 key로 하고, 빈 리스트를 value로 갖는 defaultdict(list) 형태
- 용어: 「토큰 T를 핵어(head)로 갖는 의존소」는 같은 문장 안에서 핵어 ID(다섯 번째 요소)가 T의 단어 ID(네 번째 요소)와 같은 토큰을 말한다.
- 값 표기: 따옴표 안의 글자가 데이터에 적힌 값 그대로이다. 따옴표 뒤 괄호 안의 한국어는 설명이며 비교할 값에 넣지 않는다.

함수의 작동:
1. 코퍼스 데이터 내의 각 문장에서 다음 조건을 모두 만족하는 토큰(목록 명사)을 찾는다.
   - 기본형(세 번째 요소)을 소문자로 바꾼 값이 명사 딕셔너리의 key에 포함됨.
   - 품사(두 번째 요소)가 "NOUN"임.
2. 찾은 목록 명사를 핵어로 갖는 의존소 가운데, 다음 두 조건을 모두 만족하는 의존소를 찾는다. 두 조건은 반드시 같은 의존소 하나에 대해 확인한다.
   - 그 의존소의 의존관계(일곱 번째 요소)가 "nmod:poss"(소유 수식어)임.
   - 그 의존소의 단어 형태(첫 번째 요소)를 소문자로 바꾼 값이 my, your, his, her, its, our, their 중 하나임.
3. 조건을 만족하는 의존소를 찾을 때마다 다음 작업을 수행한다.
   - 해당 문장의 모든 단어를 공백으로 연결하여 문자열로 만들고,
   - 목록 명사의 기본형(소문자)을 key로 사용하여, (문장 ID, 그 의존소의 단어 형태, 연결된 문장 문자열) 형태의 튜플을 명사 딕셔너리의 value 리스트에 추가한다.
4. 모든 문장 처리 후 수정된 명사 딕셔너리를 반환한다.

반환 (출력 데이터): 명사 용례 딕셔너리
```

```text
함수의 작동:
1. 코퍼스 데이터 내의 각 문장에서 다음 조건을 모두 만족하는 토큰(목록 명사)을 찾는다.
   - 기본형(세 번째 요소)을 소문자로 바꾼 값이 명사 딕셔너리의 key에 포함됨.
   - 품사(두 번째 요소)가 "NOUN"임.
2. 찾은 목록 명사를 핵어로 갖는 의존소 가운데, 다음 두 조건을 모두 만족하는 의존소를 찾는다. 두 조건은 반드시 같은 의존소 하나에 대해 확인한다.
   - 그 의존소의 의존관계(일곱 번째 요소)가 "nmod:poss"(소유 수식어)임.
   - 그 의존소의 단어 형태(첫 번째 요소)를 소문자로 바꾼 값이 whose임.
3. 조건을 만족하는 의존소를 찾을 때마다 다음 작업을 수행한다.
   - 해당 문장의 모든 단어를 공백으로 연결하여 문자열로 만들고,
   - 목록 명사의 기본형(소문자)을 key로 사용하여, (문장 ID, 그 의존소의 단어 형태, 연결된 문장 문자열) 형태의 튜플을 명사 딕셔너리의 value 리스트에 추가한다.
4. 모든 문장 처리 후 수정된 명사 딕셔너리를 반환한다.

반환 (출력 데이터): 명사 용례 딕셔너리
```

## 프롬프트 8. 결과 저장 함수

```text
다음 기능을 수행하는 파이썬 함수를 작성해 줘. 이 함수는 명사 용례 딕셔너리를 받아서 두 개의 텍스트 파일로 저장해야 해.
1. 명사별 용례 수와 예문을 포함한 빈도수 파일
2. 실제 용례 문장을 포함한 텍스트 파일

입력 데이터 형식: {명사: [(문장 ID, 소유자 단어, 전체 문장), …]} 형태의 딕셔너리

입력 인자:
- noun_examples_dict: 명사를 key로, 용례 리스트((문장 ID, 소유자 단어, 문장 문자열) 튜플)를 value로 갖는 딕셔너리
- folder: 출력 파일을 저장할 폴더 이름
- header: 출력 파일 이름 앞부분에 사용할 문자열
- type: 용례 유형을 나타내는 문자열 (all, pron, s, of, whose)

함수의 작동:
1. 출력 파일 이름을 생성한다. folder가 없으면 새로 만든다.
   - 빈도수 파일: "{folder}/{header}_noun_{type}_count.txt"
   - 용례 파일: "{folder}/{header}_noun_{type}.txt"
2. 빈도수 파일에는 다음 형식으로 출력:
   - 각 명사에 대해 중복(문장 ID, 소유자 단어, 문장이 모두 같은 튜플)을 제거한 후
   - 명사, 용례 개수, 첫 번째 용례 문장을 탭으로 구분하여 한 줄에 기록
   - 용례가 하나도 없는 명사는 기록하지 않는다.
3. 용례 파일에는:
   - 각 명사의 모든 (문장 ID, 소유자 단어, 문장 문자열)을 명사와 함께 탭으로 구분해 한 줄씩 기록 (명사, 문장 ID, 소유자 단어, 문장)

반환 (출력 데이터):
1. …_count.txt: 명사별 구문 유형 출현 빈도를 기록한 파일
2. ….txt: 명사별 구문 유형 용례 문장을 기록한 파일
```

## 프롬프트 9. main 함수

```text
다음 기능을 수행하는 파이썬 main() 함수를 작성해 줘. 이 함수는 'bnc_tagged.txt'와 'noun_list.txt'를 입력으로 받아, 다음 작업을 수행해야 해:

입력 파일:
- "noun_list.txt": 분석 대상 명사 목록
- "bnc_tagged.txt": 파싱된 BNC 코퍼스

수행 절차:
- 코퍼스 전처리 함수를 통해 코퍼스를 문장 단위로 분석해서 리스트 생성
- 명사 목록 전처리 함수를 통해 명사 딕셔너리를 생성
- 용례 추출 함수들을 사용해 다음 다섯 가지 용례를 추출 (함수마다 새 명사 딕셔너리를 만들어 넘긴다):
  - 전체 용례 (type: all)
  - ① 대명사 소유 용례 (type: pron)
  - ② 's 소유격 용례 (type: s)
  - ③ of 구문 용례 (type: of)
  - ④ whose 소유 용례 (type: whose)
- 결과 저장 함수를 통해 각 용례를 빈도수 파일과 용례 문장 파일로 저장 (folder: "output", header: "bnc")
- output/bnc_corpus_data.txt에 코퍼스 전처리 결과(문장 ID와 문장 텍스트)를 저장
- output/noun_dictionary.txt에 명사 목록 전처리 결과(명사 딕셔너리)를 저장

반환 (출력 데이터):
- 전처리 파일:
  - output/bnc_corpus_data.txt: 리스트 (문장 ID와 문장 텍스트)
  - output/noun_dictionary.txt: 명사 목록 딕셔너리
- 용례 파일과 빈도수 파일:
  - output/bnc_noun_*.txt: 구문 유형별 명사 용례 파일
  - output/bnc_noun_*_count.txt: 구문 유형별 명사 빈도 파일
```
